How sendit Works
Direct Device-to-Device WebRTC
Files are transferred directly between devices using WebRTC RTCDataChannel over your local WiFi. Files never touch, pass through, or get saved onto any server.
Same WiFi Discovery
Browsers cannot broadcast raw UDP/mDNS packets. sendit groups connected clients sharing the same local private network or public router IP into a shared room so you see each other in real-time.
Real Runtime Data
No fake devices, no simulated files, no fake speeds. Every device, file, progress percent, and MB/s rate is computed from real WebRTC SCTP packets and stream timers.
